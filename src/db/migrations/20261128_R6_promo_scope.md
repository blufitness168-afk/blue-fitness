# R6 — Promo subtotal and package restrictions (prepare only)

- The existing Admin/Owner promo form uses active options from `/api/packages`. `maxSatang` is the inclusive pre-discount maximum in satang, distinct from `maxDiscountSatang`. Omitted or null maximum means no ceiling; omitted or null `eligiblePackageIds` means any sellable package. An explicit array must contain 1–100 distinct, active catalog IDs at creation. Eligibility is by stable package ID, not label, catalog version, or the member's existing package. A later price change is checked against the current locked catalog in a new checkout.
- `POST /api/admin/benefits/create` routes promo payloads with the new fields to `public.r6_create_scoped_promo`. It uses the existing actor/request audit and does not fall back if the SQL entry point is missing. Legacy clients and unrestricted definitions keep their behavior. Coupon activation has no dependency on this migration and is not rewritten by it.
- Apply only after the October benefits/catalog chain and enabled catalog order guard. Install desired R3 catalog upgrades first and rehearse the exact target combination. The promo migration checks known function bodies, invoker settings, and the live trigger before patching quote, reservation, and INSERT checks in place. There is no order backfill or settlement change. Keep the migration in place once scoped promos exist; rolling SQL back to October would remove enforcement. Do not use `db:push`.
- Before enabling creation, verify the deployed trusted app role can execute the three invoker functions and has the required table, column, and sequence permissions. No `PUBLIC` execution grants are added. Review other roles/default grants before a separately authorized rollout.

Native isolated test: `python -B scripts/r6-promo-scope-postgres-test.py --bin-dir <PostgreSQL bin> [--psql <client>]`. The test uses a temporary loopback SCRAM cluster, a reduced synthetic base, and the actual checked-in payment/catalog migrations. It does not use production credentials, provider APIs, or a browser.
